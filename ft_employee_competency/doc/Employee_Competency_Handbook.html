Chapter 1

What the module does

HR decides which skills each job needs and how much each one counts. Every review period, employees rate themselves, managers give the official rating, and the module works out the scores, the skill gaps, and the actions to close them.

Six things happen in a fixed order. Nothing later works until the step before it is done.

The chain, end to end
StepWhat is builtWhereWho
1Competencies — the list of skills, grouped into categoriesCompetency ▸ ConfigurationHR
2Job competency matrix — which skills a job needs, at what level, at what weightJob Position ▸ Competency MatrixHR
3Review cycle — the period being reviewed, such as Q3 FY 2026-27Competency ▸ Assessments ▸ Review CyclesHR
4Assessments — one per employee, generated from the matrixGenerated by the cycleHR, then employee, then manager
5Scores and gaps — calculated the moment ratings are enteredOn the assessmentAutomatic
6Development plans and the competency profileCompetency ▸ DevelopmentManager, then automatic
The one rule worth learning first

A job's skill weights must total exactly 100%, and its matrix must be Validated. Until both are true, no assessment can be generated for anyone holding that job.

Chapter 2

Every word on the screen

The module uses a handful of terms consistently. Learn these and the rest of the manual reads itself.

Setup words

Competency CategoryA group of related skills — Communication, Leadership, Quality & Process. Eleven ship pre-loaded.
CompetencyOne skill, with a code such as OWN-001. Seventeen ship pre-loaded.
ScopeWhich sub-score a skill feeds: Core (expected of everyone), Functional (the craft of the job) or Leadership. A category sets the default; a single competency may override it.
Company-wideA skill every job needs. The fifteen company-wide ones total exactly 100%, so one button builds a matrix that validates with no further editing.
Development ThresholdA rating below this (default 3) marks the skill as needing development, even where the job's requirement is met.
Evidence RequiredThe manager must record a comment or evidence for this skill before the review can be completed. Ticked on all seventeen pre-loaded skills.
Required LevelThe level the job expects, 1 to 5. Rating below it is a gap.
Minimum LevelOptional. The lowest level still acceptable in the role, for telling "below target" from "below acceptable". It cannot exceed the Required Level.
Weightage %How much of the overall score a skill carries.
MandatoryA must-have skill for the role. Only mandatory skills count toward readiness for a role.
AssessInclude this skill on generated assessments. Untick to record a requirement for reference only — such a line carries no weight.
Effective From / ToOptional dates. A requirement outside these dates is skipped when assessments are generated.
Matrix StatusDraft or Validated. Only a validated matrix can produce assessments.

Review words

Review CycleThe window a round of reviews belongs to — quarterly, half-yearly or annual. Quarter-on-quarter improvement is measured from one completed cycle to the next.
AssessmentOne employee's review inside one cycle. An employee can have only one assessment per cycle.
Assessment LineOne row per skill inside an assessment. Each line copies the job matrix as it stood when the assessment was created, so re-weighting a job next quarter never rewrites a signed-off review.
ReviewerThe manager who owns the manager review. Defaults to the employee's Manager, or the department manager.
Self RatingThe employee's own rating. Reference for the conversation — it never counts toward the score.
Manager RatingThe manager's rating. The Final Rating fills in from it automatically.
Final RatingThe official rating and the only one that scores. The manager may override it.
Previous RatingThe same skill's final rating in the employee's last completed assessment, copied in when the assessment is generated.

Result words

Score %What one line contributes to the overall score.
Overall Score % · / 5The whole review, as a percentage and back on the 1–5 scale.
Core / Functional / Leadership ScoreWeighted average rating out of 5 within each scope. Leadership reads 0 and stays hidden when the job's matrix has no leadership skill.
GapFinal Rating minus Required Level.
Gap StatusNo Gap Improvement Required Critical Gap
StrengthA rating of 4 or 5 that also meets the job's requirement.
Development RequiredRating below the threshold, or any negative gap. This is what "gap" means in the counters and in the Raise Development Plans button.
ImprovementThis score minus the previous completed score. Positive means the employee improved.
Target JobThe role the employee is being grown toward. Readiness is measured against it.
Role Readiness %Share of the target job's mandatory skills the employee already meets.
Readiness StatusDeveloping Progressing Near Ready Ready
Performance / PotentialLow, Medium or High. Typed in by the manager — never calculated — and used by the Leadership Pipeline report.
Development PlanOne action against one gap, with an owner, a target date and a completion percentage.
Competency ProfileThe employee's current level in each skill. It moves only when an assessment is completed.
Chapter 3

The 1–5 rating scale

Every level in the module — required, minimum, self, manager, final, target — uses this one scale. Ratings are whole numbers only.

RatingLabel on screenRead it as
1Needs ImprovementBelow what the job can work with. Needs evidence recorded.
2DevelopingGetting there with support. Needs evidence recorded.
3CompetentDoes the job unaided. The default requirement and the default threshold.
4StrongBetter than the job asks. Counts as a strength.
5Expert / Role ModelSets the standard for others. Needs evidence recorded.
Why 1, 2 and 5 are special

These three are the ratings a reader will question, so the module insists the manager writes a Manager Comment or Evidence before the assessment can be completed. Any skill with Evidence Required ticked needs the same — and that is ticked on everything pre-loaded, so in practice every line needs a comment.

Chapter 4

Who can do what

Three roles, each one including everything the role above it can do. Set them on a user at Settings ▸ Users & Companies ▸ Users, in the Employee Competency section.

RoleSeesCan do
Employee Only their own assessment, profile and plans Enter their self rating and comments while the review is open. Read the competency list. Cannot create or delete anything.
Department Manager Their own records, plus anyone who names them as Reviewer, plus everyone in a department they manage Enter manager and final ratings, set Performance and Potential, raise and run development plans, cancel an assessment, read the reports.
HR Competency Manager Everything, in every department Everything above, plus: build categories and competencies, edit and validate job matrices, run review cycles, regenerate lines, reset an assessment or a cycle to draft. Also grants Odoo's HR Manager rights.
Before you test anything

The Competency app menu is invisible to a user with none of these three roles — an ordinary Odoo login does not get one automatically. Assign the role first, then reload the browser.

Chapter 5 · HR

Build the framework

The module installs a complete, usable framework. Most teams adjust it rather than build one from scratch.

Check what you already have

  1. Open Competency ▸ Configuration ▸ Competency Categories. Eleven categories are listed. The Default Scope column is what new skills in that category inherit.
  2. Open Competency ▸ Configuration ▸ Competencies. Seventeen skills are listed with their codes and default weights. The full list is in the appendix.

Add a skill of your own

  1. From the Competencies list, click New.
  2. Fill in Competency Name, pick a Competency Category, and give it a Competency Code — the code must be unique and is what makes spreadsheet imports possible.
  3. Set Default Weightage. This is only a suggestion offered when the skill is added to a job; each job may override it.
  4. Leave Development Threshold at 3 unless this skill needs a higher bar.
  5. Use the Evaluation Guidelines tab to describe what each of the five ratings looks like. This is the single most useful thing you can do for rating consistency — managers read it while reviewing.
  6. Tick Company-wide only if every job needs this skill. Doing so changes what the one-click matrix button produces, and will push the company-wide total off 100%.
Editing, not deleting

A skill that has ever been assessed cannot be deleted — history depends on it. Archive it instead: archived skills keep their history but are never offered for new matrix lines or generated onto new assessments.

Chapter 6 · HR

The job competency matrix

A job's matrix is the standard the people in that job are measured against. This is the step that most often blocks a first test, so it is worth doing carefully once.

Build and validate a matrix

  1. Open Employees ▸ Configuration ▸ Job Positions and pick a job. Go to the Competency Matrix tab.
  2. Click Add Company-wide Competencies. Fifteen lines appear, each at its default weight and with a required level of 3. Total Weightage % now reads 100.
  3. Add anything specific to this job — a technical skill, or a leadership skill for a job that leads. For each line set Required Level, Weight % and whether it is Mandatory.
  4. Rebalance so the total returns to exactly 100. Adding a line without reducing others is refused the moment the total passes 100.
  5. Click Validate Matrix in the header. The status badge turns Validated and the lines become read-only.

To change a validated matrix, click Reset Matrix to Draft first. Assessments already generated are untouched by anything you do here — they kept their own copy.

The three flags people mix up

FlagAffectsDoes not affect
AssessWhether the skill appears on generated assessments, and whether its weight counts toward the 100%Nothing else — an unassessed line is a note to the reader
MandatoryReadiness for the role: only mandatory skills are countedThe overall score, which uses weights alone

Chapter 7 · HR

Run a review cycle

HRDraftSet dates and coverage
HROpenReady to generate
HRAssessment RunningReviews are live
HRCompletedLocked for good
  1. Open Competency ▸ Assessments ▸ Review Cycles and click New.
  2. Name it the way the business says it — Q3 FY 2026-27. Pick the Review Type and the period's Start Date and End Date.
  3. Set the two deadlines. Self Review Deadline and Manager Review Deadline are what the daily reminder emails chase; leave them empty and no reminders go out. Neither may fall before the cycle starts, and the manager's may not fall before the employee's.
  4. On the Coverage tab, either name the employees, or name departments, or leave both empty to cover every employee in the company whose job has a validated matrix. Naming employees overrides the department list.
  5. Click Open Cycle, then Generate Assessments.

Generating does four things: it creates one assessment per employee, copies each employee's job matrix onto it, moves each one to Employee Review, and emails every employee with an activity on their to-do list. Anyone whose job has no validated matrix is skipped, and the cycle's chatter records exactly who and why. Employees who already have an assessment in this cycle are skipped silently, so you can safely press the button again after fixing a matrix.

Closing the cycle

Click Complete Cycle once every assessment is completed or cancelled. If any are still open the button refuses and names up to ten of them. After closing, the cycle and everything in it is read-only: no new assessments, no edits to ratings, dates, reviewers or summaries. An HR Competency Manager can click Reset to Draft to reopen it.

What the cycle gives you beyond tidiness

Improvement is measured between cycles. An assessment's "previous" one is the employee's most recent completed assessment from a cycle that ended before this cycle started. Overlapping cycle dates therefore break the trend columns — keep periods clean and consecutive.

Chapter 8 · Employee

The self assessment

For the employee, the whole module is two menu items and one screen.

  1. Open Competency ▸ My Competency ▸ My Assessments and open the one for the current cycle. It will be in Employee Review.
  2. On the Competencies tab, enter a Self Rating from 1 to 5 on every line. The Required Level column shows what the job asks for; Previous shows where you landed last cycle.
  3. Use Employee Comments to say what you base the rating on. Turn on the column from the ⚙ icon at the right of the header row if you do not see it.
  4. Click Submit Self Assessment. Miss a rating and the module names exactly which skills are still blank.

Submitting hands the review to your manager and closes your side of it: self ratings and employee comments can no longer be changed, because they are now part of the record being reviewed. Your rating never sets your score — the final rating your manager approves is the official one.

Where to see your own standing

Competency ▸ My Competency ▸ My Development Plans lists the actions raised against your gaps, and the actions you were made accountable for. Your own employee record's Competency tab shows your current level in every skill, your score history and your readiness for a target role.

Chapter 9 · Manager

The review

HR generatesDraftLines created from the matrix
EmployeeEmployee ReviewSelf ratings, then submit
ManagerManager ReviewManager and final ratings
ManagerCompletedProfile updated
  1. Open Competency ▸ Assessments ▸ To Review. It lists every assessment naming you as Reviewer that is still open.
  2. On the Competencies tab, enter a Manager Rating on every line. Final Rating copies it as you go; type over the final rating where you want it to differ, and say why in the comment.
  3. Write a Manager Comment or Evidence on every line. The module will not let you complete without one wherever the rating is 1, 2 or 5, or the skill has Evidence Required ticked.
  4. Watch the colours as you type: rows turn red for a critical gap, amber for improvement required and green for a strength, and the score group at the top recalculates live.
  5. On the Readiness tab, set Target Job if this person is being grown toward a role, and set Performance Rating and Potential Rating. These two are your judgement, not arithmetic, and they drive the Leadership Pipeline report.
  6. On the Summary tab, write the Strength Summary and Development Summary — the two paragraphs the employee will actually remember.
  7. Click Raise Development Plans. One draft plan is created for every gap that has none yet, each aimed at the required level, owned by you, dated to the end of the cycle.
  8. Click Complete Assessment.

Completing writes the approved final ratings onto the employee's competency profile and locks the review. If any gap still has no plan against it, the module completes anyway and posts a note in the chatter naming those skills — a gap with no plan is a management conversation, not a data error.

Chapter 10

How every number is worked out

Nothing here is entered by hand. If a figure looks wrong, one of these formulas will explain it.

A worked example

One employee, on a job carrying the fifteen pre-loaded company-wide skills. Every requirement is level 3, every threshold is 3, and every skill is Core.

The header of that assessment therefore reads Overall Score % 63.00, Overall Score / 5 3.15, Core Score / 5 3.15, Strengths 6, Critical Gaps 0 — and the gap counter, which drives the development-plan button, reads 3.

The formulas

FigureHow it is worked out
Score % (one line)(Final Rating ÷ 5) × Weight. A 4 on a 10% skill gives 8.00.
Overall Score %The sum of every line's Score %. With weights at 100%, all 1s give 20% and all 5s give 100%.
Overall Score / 5Overall % ÷ 20.
Core / Functional / LeadershipWeighted average rating inside that scope: Σ(rating × weight) ÷ Σ(weight). It is out of 5, not out of 100, and it ignores the other scopes entirely.
GapFinal Rating − Required Level. No Gap at 0 or above, Improvement Required at −1, Critical Gap at −2 or worse.
Development RequiredFinal Rating below the Development Threshold, or a negative gap. So a job that asks for 2 on a skill whose threshold is 3 still flags development at a rating of 2.
StrengthFinal Rating of 4 or more and gap of 0 or more.
ImprovementThis Overall Score / 5 − the previous one. With no previous completed assessment it reads 0, not the whole of this score.
Role Readiness %Of the target job's mandatory, active skills: how many the employee's level meets, ÷ how many there are. The employee's level comes from this assessment's final ratings first, and from their standing profile for skills this job never assessed.
Readiness StatusUnder 60% Developing · 60–75% Progressing · 75–90% Near Ready · 90% and over Ready. One override: being two or more levels short on any mandatory skill of the target job holds the status at Near Ready however high the percentage runs.

Nothing is a gap until somebody has rated it. Before a final rating exists, a line's score, gap and status are all blank rather than zero — which is why a half-finished review does not look like a disaster.

Chapter 11

Development plans

A plan is what is being done about one gap. It is the only part of the module that lives between reviews.

Raising them

  • In bulk — Raise Development Plans on the assessment creates one plan per unplanned gap.
  • One at a time — the small graduation-cap button at the end of any gap row on the Competencies tab.
  • From scratch — Competency ▸ Development ▸ Development Plans, then New. Pick the employee and the skill; a plan does not have to come from an assessment.

The fields that matter

ActionThe plan's name. Write the actual action — "Lead the Q3 migration workshop", not "Improve communication".
Action TypeTraining · Mentoring · Project / On-the-job · Certification · Exposure · Self Learning. Picking Training or Certification ticks Training Required for you, which is how HR pulls the training list.
Assigned PersonWho is accountable for the action happening — usually the manager or a mentor, not the employee. This is who the overdue email goes to.
Target DateRequired. Past this date, while the plan is still Planned or In Progress, the plan is Overdue: the row turns red, the form shows an Overdue ribbon, and a daily email starts chasing the owner.
Target LevelThe level the employee should reach once the action is done. Pre-filled with the job's required level.
Completion %Progress. It must read 100 before the plan can be marked Completed.
Result / OutcomeWhat actually changed. Fill this in when you close the plan — it is what the next reviewer reads.

Buttons run Start → Mark Completed, with Cancel and Reset to Planned available throughout. Marking a plan completed sets its completion to 100 for you.

A plan does not change a rating

Completing a plan records that the action happened. The employee's level only moves when their next assessment is completed with a higher final rating. Nothing back-dates a score.

Chapter 12

The competency profile

The profile is one row per employee per skill, holding their Current Level. Find it at Competency ▸ Development ▸ Competency Profiles, or on the Competency tab of any employee record.

  • It is written only when an assessment is completed, from that review's final ratings.
  • It only ever moves forward in time: completing an old review out of order will not overwrite a newer result.
  • Its Required Level and Gap follow the employee's current job matrix, live. Move someone to a new job and their profile gaps re-state themselves against the new job immediately — unlike an assessment line, which keeps the history.
  • Nobody types in a profile row. HR can correct one, but the honest fix for a wrong level is to correct the assessment.

What the employee form shows

The Competency tab gathers everything about one person: Resource Strength / 5 (their latest completed overall score), the previous score and the improvement between them, the number of open gaps, readiness for their Target Job, then three lists — the full competency profile, every development action, and the assessment history. Two stat buttons at the top jump to assessments and to plans.

Chapter 13

The three reports

All three live under Competency ▸ Reporting and all three count completed reviews only — an unapproved rating is not a result.

ReportOpens asAnswers
Employee Competency Pivot, grouped by employee. Measures: Final Rating, Gap, Score % Where does this person stand, skill by skill? Swap rows to Category or Cycle to see their shape or their trend.
Department Skill Matrix Pivot: departments down, competencies across Where is a department strong and where is it thin? Switch the measure to Gap to find where a department sits furthest from what its jobs require.
Leadership Pipeline List, grouped by readiness Who is ready for a bigger role? Shows the leadership score, performance, potential, readiness and critical gaps side by side. Only people with a Target Job appear here — no target job, no row.

Useful filters on the first two: Below Requirement, Critical Gap, Strengths, and the Core / Functional / Leadership split. On the pipeline: High Potential and Ready for Next Role.

Chapter 16

Known quirks

Five behaviours that are confusing rather than dangerous. They are worth knowing before you conclude something is broken.

  1. The Competency menu is invisible without a role. No user gets one automatically, including the administrator. Assign Employee, Department Manager or HR Competency Manager first.
  2. Every pre-loaded skill has Evidence Required ticked. So in practice every line needs a manager comment before the review can be completed, not only ratings of 1, 2 and 5. Untick it on the skills where you do not want that.
  3. "Start Manager Review" does not skip the self assessment. Its tooltip says it does, but it demands every manager rating, final rating and required comment first. On an untouched review it simply reports what is missing. In practice you either wait for the employee to submit, or fill the manager side in first and then press it.
  4. Employees see Manager Rating and Final Rating as editable columns. The server correctly refuses the change, so the employee gets an access error on save rather than a hidden column. Nothing is at risk; it just looks wrong.
  5. Changing the Employee on a draft assessment does not refresh Department, Job or Reviewer. Those three are filled once, when the assessment is created, and deliberately do not follow the employee afterwards — which is right for a mid-cycle transfer but surprising if you simply picked the wrong name. Set them by hand, or delete the draft and start again.

The two leadership skills

LED-001 Decision Making and LED-002 Team Development & Mentoring carry no default weight and are not company-wide. Add them to the jobs that actually lead, give them a weight there, and rebalance the rest back to 100%. Only then does the Leadership Score / 5 appear on those employees' assessments.

All of it is yours to change

The pre-loaded framework is a starting point, not a definition the module owns. Upgrading or reinstalling the module will never undo a weight, a threshold or a guideline you deliberately changed.
